# AniUz

Faqat anime ko'rsatadigan obunali striming platforma (demo versiya).

**Demo:** https://cubercaat.github.io/aniuz/

## Nimalar bor

**Foydalanuvchi ilovasi** (telefon va kompyuterda ishlaydi)
- Bosh sahifa, qidiruv, anime sahifasi, pleyer, sevimlilar, profil
- Ro'yxatdan o'tish va kirish (telefon + parol)
- Anime DNA: ko'rilgan animelarga qarab tavsiyalar
- Balans to'ldirish, tarif tanlash, obuna
- Faol qurilmalar, ko'rish tarixi

**Admin panel**
- Boshqaruv, Moliya (tushum, xarajat, sof foyda), Animelar, Reklamalar, Foydalanuvchilar, Sozlamalar
- Anime qo'shish, tahrirlash, o'chirish, plakat va video yuklash

## Admin panelga kirish

Ilovadagi «Kirish» oynasida telefon o'rniga `admin` yozing. Demo parol: `admin123`.
Parolni Sozlamalar > Xavfsizlik bo'limidan o'zgartiring.

## Muhim

Bu demo versiya. Ma'lumotlar foydalanuvchining brauzerida saqlanadi, shuning uchun:
- boshqa qurilmada ma'lumotlar ko'rinmaydi;
- to'lov (Click, Payme) haqiqiy emas, tugma balansni darhol oshiradi;
- parol va admin kirishi faqat ko'rsatish uchun.

Haqiqiy ishga tushirish uchun server va ma'lumotlar bazasi, to'lov integratsiyasi va anime litsenziyalari kerak.
